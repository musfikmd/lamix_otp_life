# 🚀 SMS Hadi / Lamix Bot — Telegram Mini App (TMA)

একটি সম্পূর্ণ প্রোডাকশন-রেডি **Telegram Mini App (TMA)** যা ভার্চুয়াল নম্বর অ্যাসাইনমেন্ট, লাইভ ওটিপি রিসিভ, ব্যালেন্স অ্যাকাউন্টিং এবং উইথড্রল ম্যানেজমেন্টের জন্য তৈরি।

---

## 📱 ফিচারের সংক্ষিপ্ত বিবরণ

1. **Telegram WebApp SDK Integration:**
   - স্বয়ংক্রিয় ইউজার প্রোফাইল ও ইউজারনেম ডিটেকশন (`window.Telegram.WebApp`).
   - হ্যাপটিক ফিডব্যাক (Light, Medium, Heavy, Success, Error).
   - ডার্ক থিম এবং ফুলস্ক্রিন এক্সপ্যান্ড সাপোর্ট।
   - ব্রাউজারে টেস্ট করার জন্য ফলব্যাক ডেমো মোড।

2. **সার্ভিসেস ও কান্ট্রি রেঞ্জ (Services Tab):**
   - WhatsApp, Telegram, Facebook, Imo, OpenAI/ChatGPT, Binance, TikTok ইত্যাদি।
   - দেশ নির্বাচন (Bangladesh 🇧🇩, USA 🇺🇸, UK 🇬🇧, India 🇮🇳 ইত্যাদি)।
   - ১ থেকে ৬ টি নম্বর একসাথে ক্লেইম করার সুবিধা।
   - সার্চ এবং ক্যাটাগরি ফিল্টার।

3. **অ্যাক্টিভ নম্বর ও লাইভ ইনবক্স (Inbox Tab):**
   - অ্যাক্টিভ ভার্চুয়াল নম্বরের লাইভ কাউন্টডাউন টাইমার।
   - **Prefix Removal Engine:** আন্তর্জাতিক ডায়াল কোড সহ বা ছাড়া কপি করার সুবিধা।
   - **1-Tap OTP Copy:** ওটিপি কোড সরাসরি এক ট্যাপে কপি।
   - **Live SMS Simulator:** অ্যাপের ভেতরেই ওটিপি ও ব্যালেন্স টেস্ট করার বাটন।

4. **ওয়ালেট ও উইথড্রল (Wallet Tab):**
   - bKash, Nagad, Rocket ও Binance পেমেন্ট মেথড।
   - সর্বনিম্ন উইথড্র ৳২০ টাকা।
   - উইথড্রল হিস্টোরি (Approved, Pending, Rejected স্ট্যাটাস)।

5. **রেফারেল ও রিওয়ার্ডস (Referral Tab):**
   - ইউনিক রেফারেল লিংক কপি ও ১-ক্লিকে টেলিগ্রামে শেয়ার।
   - ৪-লেভেল মাইলেস্টোন বোনাস রোডম্যাপ (৳১,০০০ থেকে ৳১০,০০০ পর্যন্ত)।

## 🛠️ রান করার নিয়ম (How to Run)

### ১. লোকাল সার্ভার রান করা (Frontend + Backend একসাথে):
```bash
npm start
```
ব্রাউজারে ওপেন করুন: `http://localhost:3000`

### ২. ফ্রন্টএন্ড ডেভেলপমেন্ট মোড (হট-রিলোড সহ):
```bash
npm run client:dev
```

### ৩. ফ্রন্টএন্ড বিল্ড করা:
```bash
npm run build
```

## 🤖 টেলিগ্রাম বটের সাথে যুক্ত করার নিয়ম (Setup with Telegram)

Telegram Mini App চালানোর জন্য একটি **HTTPS URL** প্রয়োজন।

### ধাপ ১: HTTPS টানেল তৈরি করুন (যেমন Ngrok বা Cloudflare Tunnel)
টার্মিনালে চালান:
```bash
ngrok http 3000
```
আপনি একটি HTTPS লিংক পাবেন, যেমন: `https://xxxx-xx-xx.ngrok-free.app`

### ধাপ ২: @BotFather এ বট ও মিনি-অ্যাপ সেটআপ
1. টেলিগ্রামে [@BotFather](https://t.me/BotFather) এ যান।
2. নতুন বট তৈরি করতে `/newbot` লিখুন এবং নাম ও ইউজারনেম দিন (টোকেনটি কপি করে `.env` ফাইলে `TELEGRAM_BOT_TOKEN` এ বসান)।
3. মিনি-অ্যাপ বানাতে `/newapp` দিন:
   - আপনার বট সিলেক্ট করুন।
   - অ্যাপের নাম ও ডেসক্রিপশন দিন।
   - **Web App URL** চাইলে আপনার Ngrok HTTPS লিংকটি দিন (যেমন: `https://xxxx.ngrok-free.app`)।
   - শর্ট নেম দিন (যেমন: `app`)।
4. অথবা বট চ্যাটে সরাসরি বাটন রাখতে `/setmenubutton` দিয়ে URL সেট করে দিন।
